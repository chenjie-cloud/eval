# PRD：简化版“坦克大战”（单文件 Canvas）

## 1. 背景与目标
在浏览器中用 HTML + CSS + JavaScript（Canvas 2D）实现一个可直接打开运行的“坦克大战”简化版单文件网页（index.html）。玩家控制坦克移动与射击，摧毁敌方坦克并保护位于底部的基地。

## 2. 目标用户与使用场景
- 面向学习与演示：打开本地 HTML 文件即可游玩
- 面向快速迭代：所有逻辑集中在一个文件中，便于阅读与修改

## 3. 核心玩法（P1 必须实现）
### 3.1 玩家操作
- 方向键：上/下/左/右移动
- 空格键：发射直线子弹（存在射速冷却）
- 玩家坦克有生命值；被击中扣血，生命归零失败

### 3.2 敌方 AI
- 敌方坦克定时生成（上方出生点），数量上限受控
- 随机移动：以一定概率改变方向；遇到障碍/边界会换向
- 随机射击：存在射击冷却；子弹直线飞行
- 与玩家交互：可击中玩家；玩家可击毁敌方

### 3.3 地图与碰撞
地图为网格（tile）组成，包含：
- 砖墙：阻挡移动；可被子弹摧毁
- 铁墙：阻挡移动；子弹不能穿透（子弹停止或反弹，按实现选择其一）
- 草地：不阻挡移动；会遮挡视线（渲染在坦克/子弹上层）
- 空地：可通行
- 基地：位于底部；被子弹击中即失败

碰撞规则：
- 坦克与地图：砖/铁墙不可穿越；草地可穿越
- 子弹与敌方：命中则消灭敌方（或扣血至 0）
- 子弹与玩家：命中扣玩家生命
- 子弹与砖墙：命中摧毁该砖块，子弹消失
- 子弹与铁墙：不能穿透（停止或反弹）；子弹最终应消失或被阻挡

### 3.4 胜负判定与流程
- 设定“需要消灭的敌人总数”（例如 10）
- 胜利：消灭达到设定总数
- 失败：玩家生命耗尽 或 基地被摧毁
- 需要有清晰的胜利/失败界面，并提供“重试/重新开始”

### 3.5 掉落与道具
- 击毁“指定敌人”（例如带标记的精英敌人或按概率）会掉落道具
- 道具类型：
  - 攻击提升：提高子弹伤害（或提高射速/一次双发，需明确）
  - 生命增加：玩家生命值 +1（或恢复一定血量）
- 规则：
  - 生命增加：可叠加（每次拾取 +1 上限可配置）
  - 攻击提升：可设置为持续 X 秒，期间拾取刷新持续时间（不叠加倍数），或叠加到上限；实现时必须在 UI 中明确表现
- 拾取方式：玩家坦克与道具碰撞即拾取，立即生效

## 4. 非核心需求（P2，可选/可简化）
### 4.1 局时限制（可选开关）
- 单局 3 分钟倒计时
- 超时：平局界面 + 重开按钮

### 4.2 操作约束
- 射击冷却（例如 250ms~500ms）
- 转向/移动更新频率受控（例如每帧按速度移动并做阻挡修正）

### 4.3 进度保存（可选）
- localStorage 保存：已消灭数量、玩家生命、计时、地图状态（可只保存关键字段）
- 支持继续上一局/重新开始（可仅提供接口与注释说明）

### 4.4 难度分层（可选）
- 简单/普通/困难：影响敌方速度、射速、场上最大敌人数、子弹速度等

## 5. 体验与 UI
- 画面：Canvas 网格风格（复古像素感即可）
- HUD：显示玩家生命、已消灭/总数、当前道具状态（攻击提升剩余时间等）
- 结束界面：胜利/失败/平局的半透明遮罩层 + 按钮/按键重开

## 6. 验收标准
- 打开 index.html 即可运行并可交互
- 玩家移动/射击可用；敌方自动生成、移动、射击可用
- 砖墙可被子弹摧毁；铁墙不可被子弹穿透
- 草地不阻挡移动且遮挡视线效果可见
- 胜利/失败判定正确且可重试
- 道具掉落与拾取生效，规则明确且 UI 可见
