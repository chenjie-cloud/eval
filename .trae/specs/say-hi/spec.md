# Greeting Spec

## Why
The user initiated the system with a greeting ("hi"), and we need to respond by setting up a basic greeting script.

## What Changes
- Create a simple script that outputs a greeting.

## Impact
- Affected specs: None
- Affected code: `/workspace/hello.sh`

## ADDED Requirements
### Requirement: Greeting Feature
The system SHALL provide a greeting script.

#### Scenario: Success case
- **WHEN** user runs the script
- **THEN** it outputs "hi".
