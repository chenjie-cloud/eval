# 贪吃蛇游戏 Spec

## 为什么
玩家需要在浏览器中获得高质量、具有现代审美和沉浸感的休闲游戏体验。传统的贪吃蛇游戏视觉效果较为陈旧，我们需要一个视觉上令人惊艳（如赛博朋克霓虹风格）的现代版本，既能展示精湛的 Web 前端设计，又能提供流畅的游戏体验。

## 改变了什么
- 设计并实现了一个基于 React 和 Tailwind CSS 的网页版贪吃蛇游戏。
- 引入了极简的深色背景与强烈的霓虹发光（Neon Glow）视觉特效。
- 添加了分数统计和基于 LocalStorage 的最高分记录功能。
- 添加了键盘防反转控制和核心游戏循环逻辑。

## 影响范围
- 影响的规范：新增 Web 前端游戏规范。
- 影响的代码：新建 React 游戏组件，设置 Tailwind 样式配置和自定义动画。

## 新增需求
### 需求：核心游戏逻辑
系统应提供一个完整的游戏循环和状态管理机制。

#### 场景：成功吃到食物
- **当** 玩家控制蛇头移动到食物所在的网格坐标时
- **那么** 蛇身长度增加一节，分数增加 10 分，并在网格空闲区域随机生成一个新的食物。

#### 场景：游戏结束
- **当** 蛇头触碰到网格边界或蛇身其他部分时
- **那么** 游戏状态变更为“结束”，停止蛇的移动，并显示最终得分弹窗及“重新开始”按钮。

#### 场景：防呆控制
- **当** 蛇正在向右移动，玩家快速按下向左键时
- **那么** 系统应忽略该反向指令，防止蛇直接撞到自己。
