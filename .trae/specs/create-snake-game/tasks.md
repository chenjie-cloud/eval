# 任务列表 (Tasks)

- [ ] 任务 1：初始化项目结构与美学设计：搭建 HTML 骨架并引入精美的 CSS 样式（如复古霓虹/赛博朋克风格），实现游戏容器和计分板 UI。
- [ ] 任务 2：实现基础游戏逻辑：使用 JavaScript 在 Canvas 或 DOM 网格上绘制蛇和食物。
- [ ] 任务 3：实现控制与移动：绑定键盘事件（方向键/WASD）控制蛇的移动方向，并设置游戏主循环（requestAnimationFrame 或 setInterval）。
- [ ] 任务 4：实现碰撞检测与得分系统：处理吃食物、撞墙、撞自己的逻辑，并实时更新分数及最高分。
- [ ] 任务 5：游戏状态管理：实现开始屏幕、暂停功能和游戏结束屏幕及重置逻辑。
