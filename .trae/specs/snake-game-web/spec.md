# 贪吃蛇 Web 游戏 Spec

## Why
用户需要一个经典的贪吃蛇 Web 游戏。为了提供卓越的用户体验和视觉表现，本项目将采用 React + TailwindCSS 技术栈，并结合“复古未来主义霓虹（Retro-Futuristic Neon）”的独特美学设计，打造一个极具吸引力、非同质化的高质量网页游戏。

## What Changes
- 初始化 React + TailwindCSS + Vite 前端项目。
- 实现贪吃蛇核心游戏逻辑（移动、进食、成长、碰撞检测、分数统计）。
- 设计并实现“复古霓虹”风格的游戏 UI 界面，包括主屏幕、游戏画布、计分板和游戏结束提示。
- 添加高质量的 CSS 动画和过渡效果（如食物的呼吸灯闪烁、吃下食物的得分特效）。
- 实现键盘事件监听以控制蛇的移动方向。

## Impact
- Affected specs: 全新项目，无影响。
- Affected code: 全新创建的项目目录及前端代码。

## ADDED Requirements
### Requirement: 游戏主界面与美学设计
系统应该提供一个复古霓虹风格的视觉界面。
#### Scenario: 成功加载页面
- **WHEN** 用户打开页面
- **THEN** 看到暗色背景（如深空黑/暗紫），发光的网格线，居中的游戏区域，醒目的霓虹风格标题和实时分数显示，使用具有个性的字体（如复古像素或等宽字体）。

### Requirement: 核心游戏控制逻辑
系统应该允许用户通过键盘箭头键控制贪吃蛇。
#### Scenario: 用户开始游戏并操作
- **WHEN** 用户点击“开始”并按下方向键
- **THEN** 蛇头改变方向，蛇身跟随移动；吃到发光的食物后，长度增加，分数上升；撞到墙壁或自身时，游戏结束并显示最终得分及“重新开始”按钮。
