# 贪吃蛇游戏 Spec

## Why
用户希望在当前项目中开发一个经典的“贪吃蛇”小游戏，以提供娱乐功能并展示前端交互开发能力。

## What Changes
- 创建一个基于 Web 技术（HTML/CSS/JavaScript）的贪吃蛇游戏。
- 实现游戏主循环、蛇的移动、食物生成、碰撞检测和分数统计。
- 设计具有一定美感的游戏界面（如复古像素风或现代极简风）。
- 响应键盘方向键进行控制。

## Impact
- Affected specs: 游戏前端界面展示、前端交互逻辑。
- Affected code: `index.html`, `style.css`, `script.js`（将在根目录下创建这些文件）。

## ADDED Requirements
### Requirement: 游戏核心逻辑
系统 SHALL 提供一个基于网格的贪吃蛇游戏。

#### Scenario: 游戏正常进行与得分
- **WHEN** 玩家按下键盘方向键（上、下、左、右）
- **THEN** 蛇改变对应的移动方向（不能直接反向移动）。
- **WHEN** 蛇头碰到食物
- **THEN** 蛇身变长一节，分数增加，并在网格内随机生成新的食物。

#### Scenario: 游戏结束与重置
- **WHEN** 蛇头碰到游戏区域的边界，或者蛇头碰到自己的身体
- **THEN** 游戏结束（Game Over），停止移动，显示最终得分并提供“重新开始”按钮。
- **WHEN** 玩家点击“重新开始”按钮
- **THEN** 游戏状态重置，蛇回到初始位置，分数清零，游戏重新开始。
