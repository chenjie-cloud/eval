# PRD：简化版《坦克大战》（单文件 Canvas）

## 1. 背景与目标
实现一个可在浏览器直接运行的简化版“坦克大战”游戏（单文件 `index.html`），玩家操控坦克移动与射击，摧毁敌方坦克并保护底部基地。提供胜利/失败判定、敌方生成与 AI 行为、地图元素与碰撞、掉落道具与效果。

## 2. 目标用户
希望在浏览器体验轻量街机射击游戏、或需要学习 Canvas + 基础游戏循环/碰撞判定的开发者与学习者。

## 3. 范围（In Scope）
### 3.1 核心玩法（必须实现）
1. **玩家操作与 AI 行为**
   - 玩家：方向键移动、空格射击，具备射速限制与移动速度。
   - 敌方：自动生成（上方出生点）、随机移动、随机射击；与地图、玩家、基地发生交互。
2. **地图与碰撞判定**
   - 地图元素：砖墙（可被子弹摧毁）、铁墙（不可穿透）、草地（遮挡视线不阻挡移动）。
   - 碰撞：坦克与砖/铁墙阻挡；子弹击中砖墙摧毁；子弹击中铁墙停止或反弹（实现其一，默认停止）。
3. **胜负判定**
   - 胜利：消灭设定数量的敌人（固定目标数）。
   - 失败：玩家生命耗尽或基地被摧毁。
   - 提供胜利/失败界面与重试逻辑（键盘或按钮）。
4. **掉落与道具效果**
   - 击毁“指定敌人”会掉落道具（通过标记/概率规则确定“指定”）。
   - 道具类型：攻击提升、生命增加。
   - 拾取后立即生效，并明确持续/叠加规则（例如：攻击提升有持续时间且不叠加，仅刷新时长；生命增加可叠加但有上限）。

### 3.2 非核心增强（可选/可简化）
1. **局时限制**：默认关闭，可通过开关启用 3 分钟倒计时；超时判平局并可重开。
2. **操作约束**：射击冷却、转向/变向最小间隔，降低卡键/滥用。
3. **进度保存**：可选 localStorage 保存与继续上一局（允许保存简化状态，如分数/生命/难度/地图破坏）。
4. **难度分层**：提供简单/普通/困难参数差异（AI 速度、射速、同时子弹数等），并在代码内标注参数。

## 4. 交互与控制
- 移动：↑ ↓ ← →（或 WASD 可选）
- 射击：Space
- 重试：R
- 可选：继续上一局/清除存档（按钮）

## 5. 玩法规则细化
1. 子弹为直线飞行；击中敌人/玩家造成伤害；击中砖墙摧毁砖墙；击中铁墙停止（或反弹，二选一）。
2. 草地只在渲染层面遮挡（覆盖在坦克上方），不参与碰撞。
3. 敌人生成：上方若干出生点，带生成间隔；总生成数量固定，与胜利目标一致。
4. 道具掉落：按固定规则（如每 N 个敌人必掉一次/或带概率且“带标记的敌人”才掉）生成在击毁地点，拾取后即刻生效。

## 6. UI/反馈
- HUD：生命值、击杀数/目标数、难度、攻击提升剩余时间（若存在）、局时倒计时（若开启）。
- 状态覆盖层：开始/暂停（可选）、胜利/失败/平局提示，提供重开与（可选）继续存档。

## 7. 验收标准（与 p1 对齐）
- 可以在浏览器中直接打开 `index.html` 游玩（无依赖）。
- 玩家移动/射击可用，敌方会生成并随机移动/射击。
- 砖墙可被子弹摧毁；铁墙阻挡子弹且不穿透；草地不阻挡移动且有遮挡效果。
- 胜利/失败判定正确，界面与重试可用。
- 道具掉落与拾取生效可验证，且叠加/持续规则明确并实现。
