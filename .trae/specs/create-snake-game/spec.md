# 贪吃蛇游戏 Spec

## 为什么 (Why)
用户需要一个从零开始开发的基于 Web 的贪吃蛇游戏。这将作为一个展示现代、美观且具有趣味性前端界面的完整项目，要求极佳的视觉效果与游玩体验。

## 变更内容 (What Changes)
- 创建一个基础的 HTML/CSS/JS 项目结构。
- 实现一个视觉效果出众、带有复古未来主义 (Retro-Futuristic) 或极简像素风的网页贪吃蛇游戏。
- 包含完整的游戏逻辑：蛇的移动、吃食物变长、碰撞墙壁或自身导致游戏结束。
- 添加计分板和最高分记录功能。
- 实现游戏状态控制（开始、暂停、重新开始）。
- 确保响应式设计和键盘控制（方向键或 WASD）。

## 影响范围 (Impact)
- 影响的规范：无（全新项目）。
- 影响的代码：工作区下的前端文件（`index.html`, `style.css`, `script.js` 等）。

## 新增需求 (ADDED Requirements)
### 需求：核心游戏机制
系统必须提供一个完整的贪吃蛇游戏循环。

#### 场景：成功吃掉食物
- **WHEN** 蛇的头部与食物所在的网格坐标重合时
- **THEN** 蛇的身体长度增加一节，分数增加，并在随机空闲位置生成新的食物。

#### 场景：游戏结束
- **WHEN** 蛇的头部撞到边界墙壁或蛇自身的身体时
- **THEN** 游戏停止，显示“Game Over”提示，并提供重新开始的选项。

#### 场景：美学与交互
- **WHEN** 页面加载及游戏进行时
- **THEN** 界面必须呈现高质量的设计（如发光效果、流畅的 CSS 动画过渡、清晰的排版），避免使用通用的 AI 风格。
