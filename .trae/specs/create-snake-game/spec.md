# 创建霓虹贪吃蛇网页游戏 Spec

## 为什么
用户希望开发一个贪吃蛇网页游戏。为了提供超越普通 AI 生成的平庸设计，本游戏将采用赛博朋克/霓虹复古街机风格，提供流畅的游玩体验和极佳的视觉反馈。

## 变更内容
- 初始化 React + Vite + Tailwind 项目。
- 设计并实现基于 CSS Grid 的游戏渲染画布，应用极具冲击力的霓虹发光视觉效果。
- 实现贪吃蛇核心逻辑（移动、吃食物、变长、加速、碰撞判定）。
- 实现霓虹风格的 UI 面板（得分、最高分、控制提示、游戏结束界面）。
- 集成虚拟摇杆/按键以支持移动端响应式游玩。

## 影响范围
- 影响的代码：从零开始创建全新的前端代码库。
- 影响的架构：新增 Zustand 状态管理来处理高频的游戏循环状态。

## ADDED Requirements
### 需求：核心游戏循环
系统必须能够按照设定的时间间隔更新蛇的位置，并处理玩家的输入改变方向。

#### 场景：成功吃到食物
- **WHEN** 蛇头坐标与食物坐标重合
- **THEN** 分数增加，蛇身长度增加一节，在随机空白位置生成新的食物，并在后续略微提高游戏速度。

#### 场景：游戏结束
- **WHEN** 蛇头撞击到画布边界或自身的身体
- **THEN** 停止游戏循环，展示带有霓虹特效的游戏结束面板，并若当前分数高于最高分则更新 localStorage 记录。
