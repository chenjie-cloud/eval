# 贪吃蛇游戏 Spec

## 为什么 (Why)
用户需要一个基于 Web 的贪吃蛇游戏。本项目旨在从零开始构建一个兼具高品质视觉设计和流畅交互体验的现代版贪吃蛇网页游戏。

## 做了什么更改 (What Changes)
- 初始化一个基于 Vanilla HTML/CSS/JavaScript 的游戏项目
- 实现游戏主逻辑：网格系统、蛇的移动、食物生成、碰撞检测（墙壁及自身）
- 添加控制系统：支持键盘（方向键/WASD）和移动端滑动（Touch Swipe）操作
- 设计视觉美学：采用复古霓虹（Retro Neon）/赛博朋克风格的 UI，增加视觉反馈（发光效果、动态网格背景）
- 实现计分系统：当前得分记录及基于 LocalStorage 的最高分记录
- 增加游戏状态管理：开始界面、游戏进行中、游戏结束及重新开始界面

## 影响 (Impact)
- 影响的特性：全新独立 Web 应用
- 影响的代码：`/workspace` 下的新增 HTML/CSS/JS 文件（如 `index.html`, `style.css`, `script.js`）

## 新增需求 (ADDED Requirements)
### 需求：核心游戏循环与渲染
系统应提供流畅的游戏主循环（基于 `requestAnimationFrame` 或固定 `setInterval`），在 Canvas 上渲染蛇和食物。

#### 场景：成功吃到食物
- **当 (WHEN)** 蛇头坐标与食物坐标重合时
- **则 (THEN)** 蛇的身体长度增加一节，得分增加，并在随机空闲位置生成新的食物。同时触发得分的视觉动画效果。

### 需求：碰撞判定与游戏结束
系统应能实时判断蛇的生死状态。

#### 场景：游戏失败
- **当 (WHEN)** 蛇头超出边界，或蛇头坐标与蛇身任一节坐标重合时
- **则 (THEN)** 触发游戏结束状态，停止主循环，显示最终得分及最高分，并展示“重新开始”按钮。

### 需求：高品质视觉与复古美学
系统界面需要跳出常规的“AI生成”风格，使用独特的复古街机霓虹风格（Neon Arcade）。
