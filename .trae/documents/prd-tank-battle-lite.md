# PRD：简化版「坦克大战」（单文件 Canvas 版）

## 1. 背景与目标
本项目交付一个可直接运行的单文件网页（`index.html`），使用 HTML + CSS + JavaScript（Canvas）实现简化版「坦克大战」：玩家操控坦克移动与射击，摧毁敌方坦克并保护底部基地。

## 2. 范围（In Scope）
### 2.1 核心玩法
- 玩家坦克：上下左右移动、空格射击；直线子弹；有生命值/复活与短暂无敌规则。
- 敌方坦克：自动生成；具备随机移动与射击；可被玩家击毁；子弹可击毁玩家、砖墙与基地。
- 胜利条件：消灭预设数量的敌人（目标击杀数）。
- 失败条件：玩家生命耗尽或基地被摧毁。
- 可重试：胜利/失败弹层与“重新开始”逻辑可用。

### 2.2 地图要素与规则
- 砖墙（可破坏）：移动阻挡；子弹命中会摧毁（一次命中或按耐久设定）。
- 铁墙（不可破坏）：移动阻挡；子弹命中被阻挡（停止/反弹之一，本项目选择“停止并消失”）。
- 草地（遮挡视线）：不阻挡移动；绘制层级在坦克/子弹之上以实现“遮挡视线”效果。
- 基地：位于底部；被子弹命中则摧毁并立即判负。

### 2.3 掉落与道具
- 指定敌人被击毁时会掉落道具（例如每 N 次击毁必掉一次，或固定序列）。
- 道具类型：
  - 攻击提升：提高玩家子弹伤害/射速/子弹速度之一；立即生效；具有持续时间；不叠加但可刷新持续时间（明确规则）。
  - 生命增加：玩家生命数 +1；立即生效；可叠加。

## 3. 非核心（可选）能力
### 3.1 局时限制（可选）
- 单局 3 分钟计时；超时判平局；提供重开选项。
- 作为可选开关提供（例如 `ENABLE_TIMER`）。

### 3.2 操作约束（建议实现）
- 射击冷却：限制最小射击间隔防止滥用。
- 转向/移动节流：限制过快转向导致卡键（可用最小转向间隔）。

### 3.3 进度保存（可选）
- localStorage 保存：击杀数、剩余生命、剩余敌人生成数、地图破坏状态、道具状态。
- 启动时可选择继续/新开（或以注释说明实现思路）。

### 3.4 难度分层（可选）
- Easy/Normal/Hard 参数差异明显：AI 速度、射击冷却、同屏最大子弹数、生成间隔。
- 在代码中集中配置参数并注释差异点。

## 4. 用户交互与界面
- 主画面：Canvas 地图 + HUD（生命、击杀/目标、道具状态、可选倒计时）。
- 结束弹层：胜利/失败/平局（可选），显示数据并可重试。
- 键位：
  - 方向键：移动/转向
  - 空格：射击
  - R：快速重开（可选）

## 5. 成功标准（Acceptance Criteria）
- 在现代浏览器（Chrome/Edge/Firefox）打开 `index.html` 即可游玩。
- P1 全部满足：玩家与 AI、地图与碰撞、胜负判定、掉落与道具立即生效并遵守叠加/持续规则。
- 稳定性：无明显卡死；游戏循环正常；重试可恢复初始状态。
