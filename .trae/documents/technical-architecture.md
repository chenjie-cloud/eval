# 极简在线二维码生成工具（技术架构）

## 1. 总览
本项目为纯前端静态 Web 应用：用户输入文本 → 前端本地生成二维码 → 以图片形式展示供右键保存。无后端、无数据存储、无登录系统。

关键设计原则：
- 本地生成：不上传输入内容
- 极简：不需要“生成”按钮，输入即触发
- 高成功率：合适的纠错级别与足够像素的输出
- 可保存：最终渲染为 `<img src="data:image/png;base64,...">` 或 Blob URL

## 2. 技术栈选择（建议）
优先选择可快速落地、产物体积小、易部署的方案：
- 构建：Vite（静态站点输出）
- 语言：TypeScript（可选，但推荐）
- UI：Vanilla + 语义化 HTML + 现代 CSS（无需 React/Vue 也能满足需求）
- 二维码生成：使用成熟的前端二维码库（例如 `qrcode` npm 包）或等价实现

说明：二维码生成需支持输出到 Canvas/SVG，并能导出 PNG。实现时优先选择：
- 支持 `toDataURL` / `toCanvas` / `toString(SVG)` 等接口
- 无网络请求依赖

## 3. 页面结构与组件划分
单页结构，建议模块边界如下：
- `App`：布局、输入状态、触发生成、错误与空态
- `qr` 模块：封装二维码生成方法
  - 输入：字符串、配置（尺寸、纠错级别、margin）
  - 输出：PNG data URL（首选）与元信息（尺寸/耗时/错误）

## 4. 状态与数据流
- `text`：输入框内容（trim 后用于判断空态）
- `debouncedText`：防抖后的内容（约 1000ms）
- `qrImageSrc`：二维码图片地址（data URL 或 Blob URL）
- `status`：`idle | generating | ready | error`

数据流：
1. 用户键入/粘贴 → 更新 `text`
2. `text` 变化触发防抖计时
3. 防抖到期 → 调用 `generateQr(debouncedText)`
4. 生成成功 → 设置 `qrImageSrc`，渲染 `<img>`
5. 生成失败 → 展示错误提示

## 5. 生成策略（清晰度与成功率）
### 5.1 防抖
- 默认 1000ms（满足“停止输入 1 秒后生成”）
- 可在实现中对短内容使用更短延迟，但必须避免频繁重算

### 5.2 二维码参数
推荐默认参数：
- 纠错级别：`M` 或 `Q`（内容较长时可提高纠错以提升鲁棒性，但会增大密度）
- `margin`：2~4（留白有助识别）
- 输出尺寸：至少 256px；根据内容长度动态提升（例如 256/320/384/512 分档）

### 5.3 输出为可右键保存的图片
为了稳定支持“右键保存图片”，优先路径：
- 生成到 Canvas → `canvas.toDataURL("image/png")` → 设置到 `<img src>`
若使用 SVG 生成：
- 将 SVG 转换为 PNG（Canvas 绘制）或直接提供 SVG 作为 `<img>`（但不同浏览器右键保存体验不一，PNG 更一致）

## 6. 性能
- 仅在防抖触发时生成，避免每次 keystroke 重算
- 对长文本生成较慢时：
  - 使用 `requestIdleCallback`（可选）或在生成前先设置 `status=generating`，避免 UI 假死
- 资源体积控制：
  - 仅引入一个二维码生成库，避免大 UI 框架

## 7. 安全与隐私
### 7.1 不收集与不传输
- 不接入任何分析脚本（默认不引入）
- 不发送网络请求（除静态资源加载）
- 不记录输入到日志/console

### 7.2 XSS/注入风险控制
- 不将用户输入作为 HTML 注入（只作为字符串传给二维码生成器）
- 页面提示文本使用静态内容或文本节点渲染

### 7.3 不泄露到 URL
- 不将输入写入 query/hash
- 不使用 `localStorage` 持久化（默认关闭）

## 8. 响应式布局
- CSS 使用 `clamp()`、`min()`、`max()` 控制输入框高度、二维码尺寸
- 桌面：两列（输入/预览）
- 移动：一列（输入在上）
- 预览区保持固定宽高比，避免布局抖动

## 9. 部署
静态站点部署即可：
- 构建输出 `dist/`
- 可部署到任意静态托管（Nginx、CDN、对象存储、GitHub Pages 等）

## 10. 测试与验收建议
- 功能：
  - 输入 URL 与普通文本均能生成并扫码识别
  - 清空输入后回到空态
  - 右键保存 PNG 后文件可打开
- 兼容：
  - Chrome / Edge / Safari（桌面与移动端）
- 性能：
  - 连续输入时不卡顿
  - 停止输入后 1 秒左右更新二维码
